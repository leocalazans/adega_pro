# **App Name**: ADEGA_PRO Lite

## Core Features:

- Offline POS: Offline-first Point of Sale (POS) interface optimized for touch and keyboard/barcode scanner input.
- Product Catalog: Inventory management with product catalog (photo, name, barcode, category, price, supplier, stock).
- Financial Dashboard: Simplified financial tracking: daily cash flow, sales reports, and best-selling product ranking.
- Contact Management: Essential customer and supplier directories for basic CRM needs.
- Smart Restock: AI tool suggesting optimal restock quantities based on recent sales data. Helps prevent shortages and reduce overstocking.

## Style Guidelines:

- Primary color: Saturated deep blue (#3F51B5) to inspire confidence in managing money and resources.
- Background color: Desaturated light blue (#E8EAF6).
- Accent color: Vibrant purple (#7E57C2) for interactive elements and highlighting key information.
- Headline font: 'Space Grotesk', sans-serif, for headlines. Body font: 'Inter', sans-serif, for body text, to combine modernity with excellent readability.
- Clean, minimalist icons to represent product categories, payment methods, and report types.
- Responsive layout adapting to mobile, tablet, and desktop screens, ensuring optimal usability on each device.
- Subtle transitions and animations to enhance user experience when navigating between sections and completing actions.
